# Product Requirements Document

## Shipped

* [Slice 1 core run](slice-1-core-run.md) - One level, one survivor, a full run: shoot zombies, level up with 20 perk cards, collect 6 gears, extract before the nuke.
* [Slice 18 directional locomotion](slice-18-directional-locomotion.md) - Player walk and run animations that depend on the angle between movement and aim: forward, backpedal and strafe clips blended in a 2D blend space, with smooth transitions.
* [Slice 2 mobile touch and web build](slice-2-mobile-touch-and-web-build.md) - Touch twin-sticks for mobile browsers and a single-threaded HTML5 export zipped for itch.io.
* [Slice 3 isometric 3D presentation](slice-3-isometric-3d-presentation.md) - Port the playable run from 2D to an isometric 3D view with placeholder meshes, keeping all gameplay, controls and tests.
* [Slice 4 sound effects](slice-4-sound-effects.md) - Give every gameplay event a placeholder sound effect so the run can be played with audio.
